# OWP to schema.org

Informative mapping of the OWP vocabulary to schema.org, for catalogs and search engines that read schema.org (for example dataset search, or Croissant descriptions of data). schema.org is not a formal ontology, so this package holds SKOS matches only: `mappings.sssom.tsv` with justification and confidence, and the same matches as OWL annotations in `align.ttl`. There are no subclass axioms to reason over. OWP conformance never depends on this package.
